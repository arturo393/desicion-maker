## 🌟 What is this?

This is a **Generic Python Library** to reduce uncertainty in complex decisions. 
It is NOT a specific app for one use case (like upgrading a Mac). It is a **Framework** you can use to model *any* decision:
*   Buying a House vs Renting.
*   Choosing a Job Offer.
*   Investment Portfolios.
*   Engineering System Architecture.

## 🛠️ Quick Start

### 1. Install Dependencies
```bash
uv sync
```

### 2. Create Your Decision Model
Copy the **Generic Template** and edit it with your factors and options.

```bash
cp generic_template.py my_decision.py
```

### 3. Edit `my_decision.py`
Define your **Factors** (what you care about) and **Options** (your choices).

```python
# Example in my_decision.py
framework.add_factor(Factor("Cost", 0.4, maximize=False))
framework.add_factor(Factor("ROI", 0.6, maximize=True))

opt = DecisionOption("Project A")
opt.add_variable("Cost", DistributionType.NORMAL, 1000, 100)
framework.add_option(opt)
```

### 4. Run the Analysis
```bash
uv run python my_decision.py
```
You will get a detailed report in the console and a Markdown/JSON file in `results/`.

## 🧠 The 6 Pillars of Analysis

1.  **🎲 Monte Carlo Engine**: Stochastically simulates 50,000+ scenarios to find the probability of success.
2.  **⚖️ Multi-Criteria Optimization (TOPSIS)**: Ranks options based on geometric distance to the ideal solution.
3.  **🧭 Strategic Compass**: Applies Game Theory (Maximin, Maximax) to match your risk profile.
4.  **⚖️ Pareto Efficiency**: Identifies and filters out strictly dominated options.
5.  **🌪️ Sensitivity Analysis**: Tests how robust your winner is against changes in Factor Importance.
6.  **🔮 Future Horizons**: Advanced experimental engines (Bayesian Inference, Real Options, Genetic Algorithms).
