## 🧠 ¿Por qué V2 estaba EQUIVOCADO?

### Error Fundamental: "Garbage In, Garbage Out"

```
V2 usó:
├─ Probabilidad venta: 60% ← ASUMIDO (no verificado)
├─ Precio venta: $120K-200K ← ASUMIDO (no validado)
├─ Demanda mercado: "Existe" ← ASUMIDO (no investigado)
└─ Matemáticas: CORRECTAS ← Pero con inputs incorrectos

Resultado: RECOMENDACIÓN PELIGROSA ❌
```

### Sesgo Identificado

| Sesgo | Causa | Consecuencia |
|-------|-------|-------------|
| Optimismo excesivo | Asumió lo mejor | 60% venta (falso) |
| Sobrevaloración | "Bien reparado" = valor | $120K-200K (falso) |
| Ignorancia mercado | No investigó demanda | NO existe (falso) |
| Falta de validación | Confió en intuición | V2 completamente wrong |

### V3 Corrección

```
V3 usó:
├─ Búsqueda Gemini API: Datos REALES internet
├─ Validación: OLX, FB Marketplace, Yapo datos reales
├─ Ajuste parámetros: 60% → 4%, $120K → $50K
├─ Matemáticas: IDÉNTICAS (pero inputs correctos)
└─ Resultado: RECOMENDACIÓN VALIDADA ✅
```
