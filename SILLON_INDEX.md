Opción 3 (Limpiar+Reparar):
  Pérdida máxima = -$160K (si falla)
  Ganancia potencial = +$125K (si funciona)
  Valor esperado = +$35K POSITIVO
```

### 2. Tienes Tiempo

```
Plazo: 1 mes

Margen: Una semana para Plan B
```

### 3. Plan B es Seguro

```
Si no se vende → Botarlo de todas formas
Costo máximo conocido → $160K
Vs. Botar hoy → $85K
Diferencia: Vale la pena intentar
