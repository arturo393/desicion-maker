# Bitácora 19-Oct-2026 — push a main, error de 3.12 y CI local

## Push y un error que sólo existía en Python 3.12

- [x] Los commits del 18-Oct subieron a `main`. La CI de GitHub falló en el job de Python 3.12: `mypy` rechazaba `core/topology.py:133`, donde el nombre `threshold` era primero la variable de un barrido sobre `np.linspace` y después el punto de corte entre clusters. Con numpy 2.5.2 (3.12) es un error de tipos; con 2.4.6 (3.11), que era lo único verificado en local, no.
- [x] Reproducido con `uv run --python 3.12 --isolated` antes de arreglarlo; el segundo uso pasó a `split_at`. mypy limpio y 730 tests verdes en las dos versiones; la CI siguiente pasó en verde.
- **Lección**: el job de 3.12 se había cortado en mypy, así que sus tests nunca corrieron. Verificar sólo la versión local deja sin ver lo que depende de la versión.
